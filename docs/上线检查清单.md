## 6. 云托管建议

当前版本建议优先走“单实例升配”：

- [ ] 保持 1 个稳定在线实例
- [ ] 提高实例 CPU / 内存规格
- [ ] 先观察单实例可承载的房间数和连接数
- [ ] 暂不做多实例横向扩容

说明：
- 当前房间状态依赖单进程内存，直接多实例容易造成房间状态不一致。
- 本版以“尽快稳定上线”为目标，先升配比先改架构更稳。
