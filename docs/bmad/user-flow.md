# 用户流程：摇骰子聚会助手（微信小程序）

- **项目：** 摇骰子聚会助手
- **日期：** 2026-03-11
- **设计：** BMAD UX Designer（AI）

---

## 1. Flow 概览

**目标：** 覆盖 P0 的端到端主流程与关键异常：大厅→建房/入房→排位→对局闭环→等待者→断线重连。

**主要角色：**
- 房主（组织者）
- 玩家（对局参与者）
- 等待者（旁观者）

**成功标准：**
- 用户能明确知道“我现在能做什么/为什么不能做”
- 对局不会因超时或中途加入而卡死
- 重连后能恢复到正确状态（或回到大厅并提示原因）

---

## 2. 流程 1：首次进入（协议同意）

```
[进入小程序]
   |
   v
[大厅 Lobby]
   |
   +-- 未同意协议? --Yes--> [协议弹层]
   |                         |  - 去隐私/用户协议页
   |                         |  - 同意并继续
   |                         v
   |                      [回到大厅]
   |
   v
[配置昵称/服务器地址]
```

异常：
- 用户拒绝同意：留在大厅并提示“同意后方可继续使用”

---

## 3. 流程 2：创建房间（房主）

```
[大厅] -> [创建房间页]
            |
            v
        [选择配置]
         - 出手方向(必选)
         - 通配1开关
         - 起叫最小数量
            |
            v
     [创建并进入房间]
            |
            v
        [房间 ready]
```

异常：
- 方向未选/起叫数量非法：前端阻止提交并提示
- WS 未连接：提示并引导修正地址（真机 127.0.0.1 不可用）

---

## 4. 流程 3：加入房间（玩家/等待者）

```
[大厅输入房间号] -> [进入房间]
                      |
                      +-- 房间 phase=ready --> [加入对局(占座位)]
                      |
                      +-- 房间 phase!=ready --> [加入等待列表]
                                                  |
                                                  v
                                           [旁观公开信息]
                                           (等下一局再入座)
```

关键说明：
- 等待者必须明确提示“本局已开始，仅可等待下一局”

---

## 5. 流程 4：排位（房主）

```
[房间 ready]
   |
   v
[房主打开排位抽屉]
   |
   v
[选玩家 -> 点座位]
   |
   +-- 座位空 --> [设置 seatIndex]
   |
   +-- 座位占用 --> [交换座位]
   |
   v
[关闭抽屉]
```

约束：
- 仅首局开局前可排位；开局后提示“已锁定”

---

## 6. 流程 5：对局闭环（摇骰→叫骰→开牌→结算）

### 6.1 摇骰（diceRolling）

```
[发起者点击开始]
  |
  v
[全员进入 rolling]
  |
  +-- [点击摇一摇] -> [仅自己收到私密骰面] -> [点击 OK]
  |
  v
[全部玩家 OK]
  |
  v
[自动进入 calling]
```

异常：
- 有玩家迟迟未确认时，房间停留在 `rolling`，其余玩家主按钮显示等待态

### 6.2 叫骰（calling）

```
[轮到我?] --No--> [等待]
   |
  Yes
   |
   v
[打开叫骰抽屉]
   |
   +-- [填入最小合法加注] (可选)
   |
   v
[确认叫骰] -> [服务端校验递增/首手/上限] -> [广播当前叫骰气泡]
```

异常：
- 叫骰非法：toast 提示（服务端为准）
- 叫骰超时：服务端自动最小合法加注并推进

### 6.3 语音叫骰（确认提交）

```
[按住语音] -> [上传语音消息]
                |
                v
          [输入/注入识别文本(mock)]
                |
                v
          [解析为 X个Y]
                |
                v
          [二次确认] -> [提交叫骰]
```

### 6.4 开牌（只开上一手）

```
[轮到我 & 存在上一手] -> [点击开牌]
           |
           v
  [公开全局骰面 + 计算 totalCount(Y)]
           |
           v
  [胜负结果] -> [下一局起始位=失败方]
           |
           v
        [ended]
```

---

## 7. 流程 6：等待者入座（下一局）

```
[房间 ready & 有等待者]
   |
   v
[房主点击 等待X]
   |
   v
[选择等待者 -> 分配空座位]
   |
   v
[等待者转为对局玩家]
```

约束：
- 对局中途不允许加入对局，只能等待

---

## 8. 流程 7：断线与重连

```
[断线]
  |
  v
[自动重连] -> [room:rejoin 带 resumeToken]
  |
  +-- 成功 --> [恢复到最新 room:state]
  |
  +-- 失败(房间不存在/被踢/无权限) --> [清空会话] -> [回大厅提示原因]
```
